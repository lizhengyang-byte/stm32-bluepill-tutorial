# STM32F103C8T6 入门讲义（GitHub 分章节版）

## 项目简介

本讲义面向零基础学习者，系统讲解以 **STM32F103C8T6（Blue Pill，俗称"蓝 pill"）开发板**为载体的 STM32 单片机入门知识，技术路线采用 **HAL 库 + STM32CubeMX 图形化配置**。

讲义按章节组织，每章独立成篇，既可顺序阅读，也可按主题跳读。全文从硬件认知、开发环境搭建开始，依次覆盖 GPIO、时钟与启动流程、外部中断、定时器、PWM、串口、ADC、DMA、I2C/SPI 与 OLED 显示，最后以 FreeRTOS 实时操作系统入门收束。

选取 STM32F103C8T6 作为入门平台的依据如下：

- 该型号是 ST 公司最经典、产量最大、公开资料最丰富的主流产品线；
- 开发板售价低廉，适合反复实验；
- HAL 库与 CubeMX 对该型号的支持最为完整，社区教程数量最多；
- 学熟该型号后，再迁移到 F4、G 等其他系列时，外设配置思路基本一致。

## 快速开始

学习本讲义需完成以下三个步骤。

**第一步：准备硬件。** 一块蓝 pill 开发板、一个 ST-Link V2 下载器或 USB 转 TTL（CH340）模块、若干杜邦线、一块面包板，以及若干 LED、电阻、按键。完整清单见第 1 章 1.12 节。

**第二步：安装软件。** 所有章节均依赖 STM32CubeMX 完成图形化配置与代码生成；在此基础上，从 Keil MDK、STM32CubeIDE、VSCode + PlatformIO 三者中任选其一作为编译器即可。选择建议如下：

- Windows 平台以省事为优先：选择 Keil MDK；
- 希望减少安装软件数量或使用 Mac/Linux：选择 STM32CubeIDE；
- 习惯 VSCode 与命令行：选择 PlatformIO。

三条工具链的差异详见第 2 章。

**第三步：点亮 LED。** 按 [第 3 章](ch03_GPIO点LED.md) 所述，在 CubeMX 中将 PC13 配置为输出，将 `ch03_led_blink.c` 中对应代码填入工程，编译并烧录。板载 LED 闪烁即表示最小开发闭环已打通。

后续章节建议按目录顺序阅读：第 4 章（时钟与启动）解释了后续所有外设的时钟来源，宜尽早阅读；第 5 章（中断）、第 6 章（定时器）是理解 PWM、串口、ADC 等后续外设的基础。

## 工程代码说明

`code/` 目录下的每个 `.c` 文件对应一章的主程序骨架，并标注了所属章节。这些文件并非完整工程——完整工程由 CubeMX 生成。读者按对应章节步骤建立工程后，将对应文件中 `USER CODE` 区段的代码复制到工程的 `main.c` 即可。各文件的具体说明见 `README_代码工程说明.md`。

## 图片说明

`images/` 目录下的配图分为两类：

- **实物照片与软件界面截图**：包括开发板、芯片、外设模块、示波器波形、CubeMX 界面等，均为公开渠道检索所得，文中已大致标注来源，仅用于教学示意。
- **示意图（SVG）**：时钟树、启动流程、寄存器结构、时序图等抽象内容采用矢量 SVG 绘制，便于放大查看与二次修改。
