# STM32 蓝pill 入门教程（GitHub 版）

> 一份从零开始的 STM32F103C8T6（Blue Pill）开发教程，边点灯边把原理讲明白。
> 这一版是按章节拆开的，每一章都是独立的一篇，可以直接挑着看，也可以按顺序从第 1 章一路读到附录。

这套教程用的是最常见的组合：**STM32F103C8T6 蓝pill 板子 + HAL 库 + CubeMX 图形化配置**。CubeMX 帮你把引脚和时钟配好、把初始化代码生成出来，你专注写业务逻辑就行——这是现在 STM32 圈子里最主流的上手方式，也是我能找到的最不容易劝退的路线。

我写的时候尽量站在"第一次摸单片机"的角度。里面的坑大多是我自己踩过的：点灯点不亮、串口乱码、时钟配错板子直接不跑、OLED 不出字、DMA 和中断打架……踩过的坑我都写进了对应的章节，希望你能少走点弯路。

## 这套教程包含什么

- **12 个章节 + 1 个附录**，从认识硬件、搭环境，一路到 GPIO、时钟、中断、定时器、PWM、串口、ADC、DMA、I2C/SPI，最后上 FreeRTOS。
- **13 个可直接抄的工程代码**（`code/` 目录），和章节一一对应，编译烧录就能跑。
- **97 张配图**（`images/` 目录）：实物照片是网上找的真实板子、模块、示波器波形；示意图是我自己画的 SVG，时钟树、中断流程、DMA 搬运这些抽象的东西，看图比看字好懂。

## 快速开始（三步走）

**第一步，备齐东西。** 一块蓝pill 开发板（十来块钱）、一个 ST-Link V2 下载器或 USB 转 TTL（CH340）模块、几根杜邦线、一块面包板和几个 LED、电阻、按键。第 1 章开头列了完整清单。

**第二步，装环境。** 装 STM32CubeMX（所有人都需要它生成代码），再从 Keil MDK、STM32CubeIDE、VSCode+PlatformIO 里挑一个编译器。我的建议：Windows 上省事就 Keil，想少装一个软件就 CubeIDE，喜欢 VSCode 就 PlatformIO。三条路的差别在第 2 章讲透了。

**第三步，点灯。** 跟着 [第 3 章](ch03_GPIO点LED.md) 用 CubeMX 配一个 PC13，把 `ch03_led_blink.c` 里的代码抄进去，编译烧录。灯闪起来的那一刻，你就入门了。

之后的顺序建议按目录走：时钟和启动（第 4 章）可以早看，它解释了后面所有外设的时钟从哪来；中断（第 5 章）、定时器（第 6 章）是理解后面 PWM、串口、ADC 的地基。

## 工程代码怎么用

`code/` 里每个 `.c` 文件是章节的主程序骨架，标注了它对应第几章。它们不是完整工程（完整工程由 CubeMX 生成），你照着章节里的步骤建好工程后，把对应文件里的 USER CODE 区代码抄进去即可。`README_代码工程说明.md` 里有每个文件的说明。

## 图片说明

`images/` 下的图分两类：

- **实物照片和软件界面截图**：从互联网检索的真实照片（板子、芯片、模块、示波器波形、CubeMX 界面等），我在文中标注了大致来源。
- **示意图（SVG）**：时钟树、启动流程、寄存器结构、时序图这类抽象内容，网上图要么糊要么带水印，我直接用代码画了 SVG——矢量图放大不糊，也方便你改。
