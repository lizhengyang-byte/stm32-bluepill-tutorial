# STM32 开发板入门综合讲义

> 从点亮第一颗 LED 到跑通 FreeRTOS —— 面向零基础学习者的系统性实战讲义
>
> 目标平台：**STM32F103C8T6（Blue Pill 蓝pill 开发板）**
> 开发方式：**STM32CubeMX + HAL 库**
> 覆盖工具链：**Keil MDK / STM32CubeIDE / VSCode + PlatformIO**（三线并行）

## 项目简介

这是一份以"世界级教程"为标准的 STM32 入门综合讲义，共 **12 章 + 3 附录**，每章统一采用 **①原理讲解 → ②代码实操 → ③运行验证 → ④常见坑** 四段式结构，并配有自测题与全项目配图。

## 硬件准备

- STM32F103C8T6 "Blue Pill" 开发板（约 ¥10–20）
- ST-Link V2 调试下载器（烧录必需）
- USB 转 TTL 串口线、面包板、LED、电阻、按键
- 可选：0.96 寸 SSD1306 OLED、电位器、SG90 舵机

## 快速开始

1. 按第 2 章安装 STM32CubeMX + 任一 IDE（Keil / CubeIDE / PlatformIO）。
2. 用 CubeMX 新建 STM32F103C8T6 工程，SYS 开 Serial Wire，时钟 72MHz。
3. 参考第 3 章：配置 PC13 为 GPIO_Output，烧录后板载 LED 闪烁。

## 配套代码

`code/` 目录下每个 `.c` 文件对应讲义某章的核心案例，均标注了应粘贴到 CubeMX 工程 `main.c` 的哪个 `USER CODE` 区段，可直接编译烧录。
